# ADR-002 co-qa问答上下文模块架构与依赖说明
日期：2026-10-29
状态：Accepted

## 1. 背景说明
本项目为CampusOverflow课程实验项目，co-qa是问答业务限界上下文。
本模块使用授课教师预先提供的DDD教学模板骨架，所有pom依赖、包结构、基础代码文件均沿用模板原始配置，不自行修改。

## 2. 模块职责说明
1. **co-qa-domain 领域层**
   职责：定义问答业务实体、聚合根、值对象、仓储接口、领域业务规则。
   内置：Question、Answer、Comment、Vote、Tags等领域对象与仓储接口。

2. **co-qa-application 应用层（用例编排）**
   职责：业务用例实现、流程编排、事务控制，调用domain领域能力。
   内置：command、port、query子包，实现查询与命令用例。

3. **co-qa-api 接口定义层**
   职责：对外接口定义、DTO、入参出参模型。

4. **co-qa-infrastructure 基础设施层**
   职责：JPA持久化适配器、Redis缓存、外部工具封装，实现domain中仓储接口。
   内置：persistence持久化实现、cache缓存实现。

5. **co-qa-interfaces 入口层**
   职责：HTTP Controller，接收前端请求，调用应用层用例。
   内置：QuestionController、AnswerController、CommentController等控制器。

## 3. 本次决策
直接采用课程下发的原始骨架，包结构、pom依赖、基础代码全部保留模板原样，不做改动。组员开发严格按照该分层结构进行编码。

## 4. 决策带来的影响
优点：和课堂示例、老师模板完全对齐，满足课程实验要求，分层清晰便于小组分工开发。
局限：为教学定制版本，和工业界标准DDD依赖流向存在区别，本次以课程模板为准。
