# PO业务评审意见记录
> 评审对象：领域聚合、实体、值对象模型

## 评审结论
领域模型基本符合本次Sprint业务需求，边界合理。

### 评审意见
1. Question聚合根：包含标题、内容、创建人、创建时间，符合业务，无问题。
2. Answer实体：依附Question，属于Question聚合内，边界划分正确。
3. Vote值对象：不独立存在，归属于Question或Answer，符合不变式约束。
4. 不变式校验：同一个用户不能重复点赞，该业务规则需要在领域层校验。

### 需要对齐的点
- 后续开发接口时，接口行为必须遵守上面的业务不变式，不能绕过领域规则。
- 新增接口都要和上面梳理的业务事件一一对应。

审批：业务逻辑通过，可以进入后续代码实现阶段。
