# Lab5 前端工程化实验报告

## 一、实验目标
1. 搭建 React + TypeScript + Vite 前端工程骨架
2. 配置 ESLint、Prettier、Husky 代码质量门禁
3. 完成 axios 封装、React Query 接入、mock 数据方案
4. 实现路由、布局与三个业务页面，完成端到端贯通
5. 验证工程化规范有效性，输出可运行、可维护的前端工程
